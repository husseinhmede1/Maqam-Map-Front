# MaqaMap Web — واجهة مقامـاب

واجهة **MaqaMap** (مقامـاب): خريطة عالمية تفاعلية تُظهر التدرّج التدريجي بين الأنماط
الموسيقية عبر العالم — لا الحدود السياسية.

مبنية على React 19 + TypeScript + Vite، وتقرأ بياناتها من `Maqam-Map-Back`.

> **الشعار:** «حيث تمتزج المقامات» / _Where the Maqams Blend_

---

## البدء السريع

```bash
npm install
cp .env.example .env
npm run dev          # http://localhost:5173
```

الواجهة تحتاج الخادم يعمل على `http://localhost:4000` (مستودع `Maqam-Map-Back`).
في التطوير تمرّ الطلبات عبر وسيط Vite، فلا حاجة لإعداد CORS إضافي.

فحص شامل قبل أي دفع:

```bash
npm run verify       # تنسيق + lint + أنواع + اختبارات + بناء
```

## البنية

```
src/
├── app/                   الهيكل العام: App · providers · الترويسة
├── features/              كل ميزة مكتفية بذاتها
│   ├── atlas/             الخريطة: مكوّنات · خطّافات · منطق الرسم النقي
│   │   ├── lib/           projection · color-field · renderers · geometry
│   │   ├── hooks/         useAtlasMap · useCanvasSurface
│   │   └── workers/       حساب حقل الألوان خارج الخيط الرئيسي
│   ├── region-panel/      اللوحة الجانبية للمنطقة المختارة
│   ├── songs/             قائمة الأغاني
│   ├── player/            المشغّل + متجره العام
│   └── journey/           شريط «رحلة المقام»
├── shared/                api · i18n · store · hooks · ui · styles
└── types/atlas.ts         عقد الواجهة مع الخادم
```

**قواعد معمارية:**

1. الميزات لا تستورد من دواخل بعضها؛ ما يُشارَك ينتقل إلى `shared/`.
2. منطق الرسم في `features/atlas/lib` **دوال نقية** لا تعرف React ولا الشبكة —
   ولهذا هي مختبَرة بالكامل.
3. حالة الخادم في React Query، وحالة الواجهة في متاجر zustand صغيرة. لا خلط.
4. لا نصّ مكتوب داخل مكوّن: كل الكلمات في `shared/i18n/locales`.

### لماذا Canvas وليس SVG أو DOM

١٠٨ نقاط + ٣١ مضلعاً + ٥ مسارات متحرّكة، بحقل لوني محسوب لكل بكسل. طبقتان:

| الطبقة    | ما ترسمه                           | متى تُعاد                           |
| --------- | ---------------------------------- | ----------------------------------- |
| `base`    | اليابسة الملوّنة + السواحل         | عند التكبير/التحريك/تغيير الحجم فقط |
| `overlay` | النقاط والتسميات والمسارات النابضة | كل إطار (`requestAnimationFrame`)   |

**لا تدمجهما** — الفصل هو سبب بقاء النبض ٦٠ إطاراً/ثانية.

خطوط السواحل تُرسم متجهةً كل إطار (لا تُخبَز في الصورة) لتبقى حادة عند تكبير ×٩.

### حقل الألوان (جوهر المشروع بصرياً)

كل بكسل = متوسط موزون معكوس المسافة (IDW بقوة ٣) لألوان المناطق الـ١٠٨ كلها.
هذا ما يجعل الأنماط تمتزج بلا حدود حادة.

الكلفة ≈ ٥٫٩ مليون عيّنة، ولذلك:

- يعمل الحساب في **Web Worker** (`workers/color-field.worker.ts`)، فلا يتجمّد التمرير.
- النتيجة تُخبَّأ في canvas خارج الشاشة ويُعاد استخدامها في كل تحريك.
- الدالة نفسها نقية (`lib/color-field.ts`) وتُستخدم كمسار احتياطي إن تعذّر الـWorker.

⚠️ تغيير لون منطقة واحدة يحرّك ألوان كل ما حولها. راجع `CLAUDE.md` §٧ قبل ذلك.

### الحالة (State)

| النوع                               | الأداة                      | لماذا                                                           |
| ----------------------------------- | --------------------------- | --------------------------------------------------------------- |
| بيانات الخادم                       | React Query                 | تخبئة، إعادة محاولة، حالات تحميل/خطأ جاهزة                      |
| اللغة · المنطقة المختارة · المسارات | zustand (`app.store`)       | حالة صغيرة يقرأها الكل                                          |
| المشغّل                             | zustand (`player.store`)    | شريط ثابت + قائمة الأغاني يحتاجان نفس الحالة                    |
| موضع الخريطة (`k, tx, ty`)          | `useRef` داخل `useAtlasMap` | التحريك يُطلق أحداثاً بمعدّل الشاشة؛ حالة React هنا تقتل الأداء |

### ثنائية اللغة

`Dictionary` واجهة TypeScript: **أي مفتاح جديد لا يُترجَم في اللغتين يصبح خطأ ترجمة**،
وهناك اختبار يقارن مفاتيح `ar` و`en` مفتاحاً بمفتاح. تبديل اللغة يقلب `dir`
و`lang` وكل النصوص وأسماء المناطق المرسومة على canvas وحتى الأرقام (`٣` مقابل `3`).

## إمكانية الوصول والأداء

- `prefers-reduced-motion` يوقف النبض والخطوط المتحرّكة تماماً.
- تفاعل موحّد للفأرة واللمس عبر Pointer Events (سحب، قرص، عجلة، نقر مزدوج).
- اختيار المنطقة بالنقر وحده (فأرةً ولمساً): التحويم لا يغيّر شيئاً، والتفريق بين
  النقر والسحب عبر عتبة حركة ٤px حتى لا يُفهم السحب كنقر.
- كثافة البكسل محدودة بـ×٢ حتى لا تنهار هواتف ×٣ و×٤ تحت حقل الألوان.
